# Pasta Audio

Coloque seu arquivo de áudio aqui!

## Formatos suportados:
- `.mp3` (recomendado)
- `.wav`
- `.ogg`

## Como usar:
1. Renomeie seu arquivo de áudio para `audio.mp3`
2. Coloque o arquivo na pasta `app/src/main/assets/audio/`
3. Recompile o app

O áudio tocará automaticamente em loop quando o app for aberto.
